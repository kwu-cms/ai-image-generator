# クイックスタートガイド

ローカル開発環境でサーバーを起動する方法です。

## 前提条件

- Node.js（v18以上）がインストールされていること
- npmがインストールされていること
- `.dev.vars`ファイルに必要な環境変数が設定されていること

## 方法1: 1つのコマンドで起動（注意が必要）

`dev:pages`コマンドは静的ファイルを配信しますが、**APIサーバーも別途起動する必要があります**。

### 1. 依存関係のインストール（初回のみ）

```bash
npm install
```

### 2. ターミナル1: Workers APIの起動

```bash
npm run dev
```

### 3. ターミナル2: Pagesサーバーの起動

```bash
npm run dev:pages
```

### 4. ブラウザでアクセス

```
http://localhost:8788
```

**重要:** `dev:pages`は`--proxy http://localhost:8787`オプションでAPIをプロキシしますが、Workers API（`npm run dev`）が先に起動している必要があります。

---

## 方法2: 2つのターミナルで起動

従来の方法です。フロントエンドとAPIを別々のターミナルで起動します。

### 1. 依存関係のインストール（初回のみ）

```bash
npm install
```

### 2. ターミナル1: Workers APIの起動

```bash
npm run dev
```

正常に起動すると、以下のようなメッセージが表示されます：

```
Ready on http://localhost:8787
```

### 3. ターミナル2: 静的ファイルサーバーの起動

**方法A: http-serverを使用（推奨）**

```bash
cd public
npx http-server -p 8080 --cors
```

**方法B: Pythonを使用**

```bash
cd public
python3 -m http.server 8080
```

### 4. ブラウザでアクセス

```
http://localhost:8080
```

## 動作確認

### 画像生成の確認

1. ログインページでユーザー登録またはログイン
2. TOPページでプロンプトを入力（例：「美しい夕日の風景」）
3. 「画像を生成」ボタンをクリック
4. 生成結果が表示されることを確認

### 履歴の確認

1. ナビゲーションの「履歴」をクリック
2. 生成した画像とプロンプトが一覧表示されることを確認

## トラブルシューティング

### ポートが既に使用されている場合

**エラー: `EADDRINUSE: address already in use`**

別のポートを使用するか、既存のプロセスを終了してください：

```bash
# ポート8787を使用しているプロセスを確認
lsof -ti:8787

# プロセスを終了（PIDを確認してから）
kill -9 <PID>
```

### APIに接続できない場合

- Workersが`http://localhost:8787`で起動しているか確認
- ブラウザのコンソール（F12）でエラーを確認
- CORSエラーが出る場合は、`--cors`オプションを確認

### 環境変数が設定されていない場合

`.dev.vars`ファイルが存在し、必要な環境変数が設定されているか確認してください：

```bash
cat .dev.vars
```

Workersを起動したターミナルで、リアルタイムにログが表示されます。

### データベースの確認

```bash
# ローカルデータベースの確認
wrangler d1 execute image-generation-db --local --command "SELECT * FROM images LIMIT 10"
```

## 注意事項

- ローカル開発時は、`.dev.vars`の環境変数が使用されます
- 本番環境とは異なるデータベース（ローカル）が使用されます
- 画像はローカルのR2シミュレーターに保存されます（本番のR2には保存されません）
