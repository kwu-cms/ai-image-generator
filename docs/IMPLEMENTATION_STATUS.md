## 使用方法

### 参照画像を追加して画像生成
1. 「参照画像を追加」ボタンをクリック
2. 「ファイルを選択」または「既存から選択」で画像を選択
3. 役割ラベルを選択（必要に応じてカスタム入力）
4. プロンプトを入力
5. 「画像を生成」ボタンをクリック

### 既存の参照画像から選択
1. 「既存から選択」ボタンをクリック
2. モーダルで表示範囲を選択（全て、自分の画像、クラス共有、教員固定サンプル）
3. 画像をクリックして選択

### 履歴での参照画像確認
1. 履歴ページで生成画像を確認
2. 参照画像サムネイルをクリックして拡大表示
