## OpenAI APIの課金について

### 基本情報

- OpenAI APIは使用量ベースの課金です
- 新規アカウントには無料クレジット（$5程度）が付与されることがあります
- クレジットを使い切ると、課金設定が必要になります
- DALL-E 3の料金: 画像1枚あたり約$0.04〜$0.12（サイズによる）

### エラー「Billing hard limit has been reached」が表示される場合

1. [OpenAI Usage](https://platform.openai.com/usage) でクレジット残高を確認
2. 支払い方法を登録する必要がある場合があります
3. 使用量制限を確認・調整してください

## 授業運用における課金額の見積もり

### 運用条件

- **期間**: 1ヶ月
- **学生数**: 100人
- **1人あたりの生成枚数**: 10枚
- **総生成枚数**: 1,000枚

### DALL-E 3の料金（2024年1月時点）

現在の実装では以下の設定を使用しています：
- **モデル**: DALL-E 3
- **サイズ**: 1024x1024
- **品質**: standard

#### 料金表

| サイズ | Standard品質 | HD品質 |
|--------|-------------|--------|
| 1024x1024 | $0.040/画像 | $0.080/画像 |
| 1792x1024 | $0.080/画像 | $0.120/画像 |
| 1024x1792 | $0.080/画像 | $0.120/画像 |

### 課金額の計算

#### 基本計算（Standard品質、1024x1024）

```
総生成枚数: 100人 × 10枚 = 1,000枚
単価: $0.040/枚
総額: 1,000枚 × $0.040 = $40.00
```

#### 為替レートを考慮した場合（1ドル=150円の場合）

```
$40.00 × 150円 = 6,000円
```

### 推奨設定

#### 初期クレジット購入

**推奨額: $50.00**

理由：
- 基本計算で$40.00が必要
- 余裕を持たせるため+$10.00
- テストやエラー時の再生成を考慮

#### 自動チャージ設定（オプション）

授業運用では、以下の設定を推奨します：

1. **自動チャージ**: 有効
2. **残高が下回ったら**: $10.00
   - 残り約250枚分のクレジット
   - 緊急時のバッファとして機能
3. **残高を戻す額**: $50.00
   - 1ヶ月分の運用に十分なクレジット
4. **月間自動チャージ上限**: $100.00
   - 予想外の使用量増加に対応
   - 上限を設定することで予算管理が可能

### コスト削減のヒント

#### 1. 画像サイズの調整

現在の設定（1024x1024）のままが最もコスト効率が良いです。

#### 2. 品質設定

- **Standard品質**: $0.040/枚（推奨）
- **HD品質**: $0.080/枚（2倍のコスト）

授業用であれば、Standard品質で十分です。

#### 3. 使用量の監視

- [OpenAI Usage](https://platform.openai.com/usage) で使用量を定期的に確認
- 予想より多く使用している場合は、学生に注意喚起

### 予算計画

#### 最小予算

```
初期クレジット: $40.00（約6,000円）
自動チャージ: なし
```

#### 推奨予算（余裕を持たせる）

```
初期クレジット: $50.00（約7,500円）
自動チャージ: 有効
  - 残高が$10以下になったら$50を追加
  - 月間上限: $100
```

#### 最大予算（安全策）

```
初期クレジット: $100.00（約15,000円）
自動チャージ: 有効
  - 残高が$20以下になったら$50を追加
  - 月間上限: $150
```

### 注意事項

1. **為替レート**: 実際の支払額は為替レートにより変動します
2. **使用量の変動**: 学生によって生成枚数が異なる可能性があります
3. **エラー時の再生成**: APIエラー時の再試行も課金対象です
4. **テスト運用**: 事前のテスト運用も課金対象です

### まとめ

**推奨設定:**
- 初期クレジット: **$50.00（約7,500円）**
- 自動チャージ: 有効
  - 残高が$10以下になったら$50を追加
  - 月間上限: $100

これで1ヶ月の授業運用に十分なクレジットを確保できます。

## 履歴管理の仕組み

### 概要

生成された画像とプロンプトは、以下の2つの場所で管理されています：

1. **画像ファイル**: Cloudflare R2ストレージ
2. **メタデータ**: Cloudflare D1データベース

### データフロー

```
ユーザーがプロンプトを入力
  ↓
Workers APIがOpenAI DALL-E APIを呼び出し
  ↓
生成された画像をダウンロード
  ↓
R2ストレージに画像をアップロード
  ↓
D1データベースにメタデータを保存
  ↓
履歴ページで一覧表示
```

### データベーススキーマ

#### images テーブル

```sql
CREATE TABLE images (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    prompt TEXT NOT NULL,
    image_url TEXT NOT NULL,
    user_id INTEGER,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

- `id`: 自動採番の一意ID
- `prompt`: 画像生成に使用したプロンプト
- `image_url`: R2ストレージ上の画像パス（`/api/image/images/xxx.png`形式）
- `user_id`: ユーザーID（ログイン機能実装後）
- `created_at`: 作成日時（自動設定）

#### users テーブル

```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    email TEXT UNIQUE NOT NULL,
    student_id TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    last_login DATETIME,
    reset_token TEXT,
    reset_token_expires DATETIME
);
```

### ストレージ構造

#### R2バケット構造

```
image-generation-storage/
  └── images/
      ├── 1705123456789-abc123.png
      ├── 1705123457890-def456.png
      └── ...
```

ファイル名の形式: `{タイムスタンプ}-{ランダム文字列}.png`

### APIエンドポイント

#### 画像生成

```
POST /api/generate
```

リクエスト:
```json
{
  "prompt": "美しい夕日の風景"
}
```

レスポンス:
```json
{
  "success": true,
  "prompt": "美しい夕日の風景",
  "image_url": "/api/image/images/1705123456789-abc123.png",
  "timing": {
    "total": "25.3",
    "generation": "20.1",
    "download": "2.5",
    "upload": "2.7"
  }
}
```

#### 履歴取得（ユーザーごと）

```
GET /api/history
```

レスポンス:

#### 全画像取得（公開）

```

```

レスポンス:

#### 画像配信

```
GET /api/image/{ファイルパス}
```

例: `GET /api/image/images/1705123456789-abc123.png`

## データの保持とプライバシー

### データの保持

- **現在**: データは無期限に保存されます
- **将来の予定**: ユーザーごとの履歴管理と削除機能が実装済み

### プライバシー

- **ユーザー認証**: ログイン機能が実装済み
- **ユーザーごとの履歴**: 各ユーザーは自分の履歴のみ閲覧可能
- **公開画像一覧**: TOPページでは全ユーザーの生成画像が一覧表示されます（プロンプトと画像のみ、ユーザー情報は非表示）

### パフォーマンス

- **履歴取得**: D1データベースから取得（通常100ms未満）
- **画像表示**: R2ストレージから配信（CDN経由で高速）
- **履歴の並び順**: 作成日時の降順（新しいものから）
- **全画像一覧**: 最新100件を取得

### 制限事項

- 現在の実装では削除機能がありません（将来の実装予定）
- ページネーションは実装されていません（全履歴を一度に取得）
- 検索・フィルタ機能は実装されていません（将来の実装予定）

### 今後の改善予定

1. 画像削除機能の実装
2. ページネーションの実装
3. 検索・フィルタ機能の実装
4. 画像のエクスポート機能
