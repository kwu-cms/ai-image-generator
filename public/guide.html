履歴管理について

データの保存場所

生成された画像とプロンプトは以下のように管理されています：

  • 画像ファイル: Cloudflare R2ストレージに保存されます
  • プロンプトとメタデータ: Cloudflare D1データベース（SQLite互換）に保存されます

保存される情報

  • プロンプト（画像生成に使用したテキスト）
  • 画像のURL（R2ストレージ上のパス）
  • 作成日時

データの保持期間

現在の実装では、データは無期限に保存されます。削除機能は実装されていませんが、将来的に追加予定です。

プライバシー

ログイン機能により、ユーザーごとの履歴管理が可能です。

生成時間について

画像生成には以下の処理が含まれます：

  1. 画像生成: OpenAI DALL-E APIによる画像生成（通常10〜30秒）
  2. 画像ダウンロード: 生成された画像のダウンロード（1〜3秒）
  3. ストレージ保存: R2ストレージへのアップロード（1〜2秒）
  4. データベース保存: メタデータの保存（1秒未満）

合計時間: 通常15〜35秒程度かかります。

生成結果画面に処理時間が表示されます。詳細をクリックすると、各処理の時間を確認できます。

技術スタック

  • フロントエンド: HTML/CSS/JavaScript + Bootstrap 5（GitHub Pagesでホスティング）
  • バックエンドAPI: Cloudflare Workers（サーバーレス関数）
  • データベース: Cloudflare D1（SQLite互換）
  • ストレージ: Cloudflare R2（画像ファイル保存）
  • 画像生成API: OpenAI DALL-E 3
